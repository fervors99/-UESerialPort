高性能、工业级串口通信插件，专为 Unreal Engine 5.7+ 设计。基于 Rust 构建，提供线程安全、内存安全的串口通信能力。

## 🚀 核心特性

- ✅ **跨平台支持**: Windows, Linux, macOS
- ✅ **线程安全**: 完全的多线程支持，无数据竞争
- ✅ **内存安全**: 零拷贝设计，自动内存管理
- ✅ **高性能**: 优化的缓冲区管理和 JSON 解析
- ✅ **工业级可靠性**: Panic 隔离、锁毒化恢复、句柄验证
- ✅ **动态传感器数据**: 支持 1-256 个传感器点
- ✅ **智能缓冲区**: 自动溢出处理、实时监控
- ✅ **蓝图友好**: 所有功能均可在蓝图中使用
